# Зависимости

Страница опирается на несколько скиллов. Шаблон уже содержит их главные правила, поэтому без них страница соберётся, но новые виджеты, сцены и тексты получатся хуже.

| Скилл | Откуда | Что даёт | Без него |
|---|---|---|---|
| `artifact-design`, `artifact-capabilities`, `artifact-diagramming`, `dataviz` | встроены в Claude Code | контракт страницы claude.ai, хранилище, схемы, графики | без Claude Code страница живёт локальным файлом, выбор уходит через кнопку экспорта |
| `stageshow` | `npx skills add benjitaylor/skills`, затем `npm install` в папке скилла | анимированные сцены интерфейса | вместо сцены пошаговый разбор или переключатель ситуаций |
| `apple-design`, `emil-design-eng` | `npx skills add emilkowalski/skill` | движение, нажатия, раскрытие по шагам | правила из шаблона и [components.md](components.md) |
| `web-design-guidelines` | `npx skills add ehmo/platform-design-skills` | доступность, клавиатура, адаптивность | правила из [components.md](components.md) |
| `redaktura-skills:statya`, `redaktura-skills:redaktura` | плагин Claude Code из `N1arko/redaktura-skills` | структура и редактура русского текста | правила из [language.md](language.md) |

Скрипты требуют Python 3 (только стандартная библиотека) и Node 20 для сборки сцен.

## Как поделиться скиллом

В скилле нет ничего, что привязывает его к одной компании или одному человеку. Личные правила (стиль текста, согласование сообщений, трекер задач, язык) живут в CLAUDE.md и памяти каждого, скилл их только уважает. Примеры в `examples/` на выдуманных данных.

- **Git.** Папка `decision-page` и есть репозиторий: `SKILL.md` в корне, рядом `README.md`. Коллеги клонируют его в `~/.claude/skills/decision-page` или в `~/.agents/skills/decision-page`.
- **npx.** Из публичного репозитория на GitHub ставится одной командой: `npx skills add <владелец>/<репозиторий>`. Обновление: `npx skills update decision-page`.
- **Разные аккаунты Claude.** Страница публикуется в аккаунте того, кто работает со скиллом, и по умолчанию видна только ему. Хранилище выбора у каждой страницы своё.

## Что зависит от окружения

| Окружение | Что работает |
|---|---|
| Claude Code в приложении Claude Desktop или на claude.ai | всё: публикация страницы, хранилище выбора, чтение выбора Claude, вид как у приложения |
| Claude Code в терминале без инструмента Artifact | страница собирается локальным файлом и открывается в браузере, выбор хранится в браузере и передаётся Claude кнопкой «Скопировать выбор текстом» |
| другие агенты (Codex и подобные) | то же, что в терминале: шаблон, сборка и проверка не зависят от Claude |

Сценам нужен установленный `stageshow` и Node 20, без них страница собирается без сцен.
