# Язык страницы

Читатель занят и открывает страницу между другими задачами. Текст должен читаться с первого раза, без словаря и без возврата назад.

## Правила

- **Ответ первым.** Вердикт в меню, ответ в заголовке вопроса, объяснение под ним, подробности под раскрытием.
- **Каждый факт один раз.** Повтором считается тот же вывод или та же цифра в тексте. Цифра, которую показывает виджет (подпись полосы, шаг пути), повтором не считается. Если вывод нужен в двух вопросах, во втором дай ссылку (`data-goto`).
- **Сколько текста видно сразу.** Заголовок ответа и абзац под ним до 120 слов. Факты, подписи виджетов и варианты решений не считаются.
- **Короткие абзацы.** Одна мысль, две-три фразы.
- **Без оценок вместо фактов.** Не «критичная проблема», а «2 132 человека за две недели не смогли оформить заказ».
- **Цифры для людей.** «327 тыс.», «9,3 %», «примерно каждый десятый». Период и источник рядом с цифрой. Число событий переводи в людей и долю.
- **Честная уверенность.** «Проверено на 4 событиях из 300», «по коду, без воспроизведения». Сомнительное в блок «Что я не проверил».
- **Варианты решений.** Глагол и последствие: «Исправить в общем коде. Закроет такие же события у других команд».

## Термины

Сленг и англицизмы заменяй русскими словами. Если без термина нельзя (его увидят в интерфейсе инструмента или в коде), оставь его кнопкой-пояснением `.term`.

| Вместо | Пиши |
|---|---|
| issue, ишью | группа событий |
| event, ивент | событие |
| sample rate, сэмплирование | отправляется каждый десятый случай |
| deeplink | ссылка в приложение |
| WebView | встроенный браузер |
| flow, флоу | сценарий, путь |
| endpoint | адрес запроса |
| tag, extra | метка, дополнительное поле |
| release | версия |
| feature flag | настройка на сервере |
| retry | повтор |
| timeout | истекло время ожидания |
| race condition | гонка (поясни, кто с кем) |
| user | человек, пользователь |
| fix, пофиксить | исправление, исправить |
| задеплоить, выкатить | выпустить |

Код, запросы и названия полей остаются как есть, в `<code>`.

## Черновик ответа

Ответ пишется для адресата, а не для владельца. Привычные адресату термины в нём можно оставить латиницей как есть (issue, host, extra), если он сам так пишет. Транслитерацию («сэмпл», «хотфикс», «ишью») не используй: пиши по-русски («выборка», «срочное исправление») или латиницей. Начало с обращения, по абзацу на вопрос, в конце что будет дальше. Фразы для каждого варианта решения пиши так, чтобы любая комбинация читалась связно.

## Редактура

Русский текст после сборки прогони через `redaktura-skills:redaktura`, если скилл установлен: смысл, структура, канцелярит, штампы, следы нейросети. Для страниц-статей с длинным текстом структуру сверяй со `redaktura-skills:statya`. Правила проекта о стиле (например, запрет длинного тире или транслитерации) главнее, `scripts/build.py` предупреждает о длинных тире.
